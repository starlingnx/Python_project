# 📂 Smart File Organizer

A Python script that automates the boring process of organizing cluttered directories. It scans your folder and automatically sorts files into subdirectories based on their extensions.

## 🚀 Features
- **Zero Dependencies:** Uses only built-in Python modules (`os`, `shutil`).
- **Auto-Categorization:** Sorts files into Music, Code, Images, Documents, and Archives.
- **Unrecognized Files:** Safely moves unknown formats to an `Others` folder.

## 🛠️ How to Use
1. Clone this repository or download the `main.py` file.
2. Place `main.py` in the messy directory you want to organize.
3. Open your terminal in that directory and run:
   ```bash
   python main.py
